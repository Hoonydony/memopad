# Look_at_me

A simple multi-tab notepad application built with Python and Tkinter.  


## Build Instructions

**Python 3.9 or later**  
**tkinter** (included in most Python installations)  
**macOS** (this project is currently built for macOS)

## How to Use
You will name the first tab once you open the application after building while the Git has already built it.

<img width="796" height="627" alt="image" src="https://github.com/user-attachments/assets/ba6b47cb-127b-4025-a441-33dc93d01882" />

You can switch tabs by clicking the tab bar. If you want to rename a tab, double-click the tab, rename, and insert Enter.

<img width="912" height="740" alt="image" src="https://github.com/user-attachments/assets/7f21a2cc-33f2-468f-94e2-98fea8c9eaa8" />

You can change the font style independently as you wish. You need to put a number manually for font size. Bold and Underline can be applied with clicking each button, or with Command+B and Command+U.

<img width="800" height="628" alt="image" src="https://github.com/user-attachments/assets/3197e527-28de-4a3a-a3ab-821c044d2032" />

The current tab will be saved through Save button in the text format.
